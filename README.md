# STM32F103 + MT6701 有感 FOC 学习工程

基于 STM32F103C8、MT6701 编码器和 STM32 HAL，实现电流、速度、位置串级控制，并通过串口进行限时阶跃和 PI 参数调整。工程用于记录 FOC 学习、联调和排错，不是量产驱动器或可直接套用的工业伺服方案。

> **安全提示：上电初始化会主动施加约 400 ms 的转子对齐电压，即使没有发送运行命令也可能转动。** 首次复现必须核对驱动板、电流采样、相序、编码器方向和电源限制，固定电机并远离旋转部件。软件限流不代替驱动器硬件保护；不要把 MCU 引脚直接连接电机绕组。

## 功能与当前状态

| 内容 | 当前实现 | 边界 |
| --- | --- | --- |
| 有感 FOC | MT6701 SPI DMA 读角度、双 ADC 电流采样、Clarke/Park 变换、SVPWM | 不含无感观测器；需要适配实际功率板 |
| 三环控制 | 电流 PI、速度 PI、位置 P/PI；当前应用入口为位置模式 | 并非 RTOS 工程；速度与电流内环由配置固定 |
| 初始化 | ADC 硬件自校准、256 点电流零偏平均、固定电压对齐 | 校零须满足无电流条件；对齐强度依赖硬件 |
| 串口联调 | PING、STOP、SET_PID、RUN_STEP、位置遥测 | 简单文本协议，无 CRC、序号或重传，不保证硬实时 |
| 故障处理 | 相电流越限、运行中编码器停更等触发停机 | 独立硬件断能、堵转、负载与长时间可靠性尚未完整验证 |

纯 P 分支直接计算并限幅 `Kp * error`，避免把限幅后的历史输出带入纯 P 递推而留下位置偏差。非纯 P 的 PI/PID 分支仍使用 CMSIS 递推及输出回写，不能据此声称所有抗饱和问题均已解决。

## 硬件、构建与启动

| 项目 | 源码中的配置 | 复现说明 |
| --- | --- | --- |
| MCU / 时钟 | STM32F103C8；8 MHz HSE、PLL ×9；64 KB Flash、20 KB RAM 工程配置 | 使用自己的实际器件和时钟，不照搬不匹配的存储容量 |
| 编译入口 | `MDK-ARM/OLED.uvprojx`，目标名保留为 OLED | Keil µVision，项目记录的编译器为 Arm Compiler 6.21；需要相应器件支持包 |
| 配置入口 | `OLED.ioc`、`Drivers/FOC/foc_config.h` | 保留 CubeMX 配置；修改定时频率时核对定时器字面值与控制器 dt |
| PWM U/V/W | TIM1 CH1/2/3：PA8 / PA9 / PA10 | 连接匹配的三相驱动板；极性、使能和硬件保护须另核对 |
| 电流 U/V | ADC1 CH0 / ADC2 CH1：PA0 / PA1 | W 相重建；当前假定 0.02 Ω、增益 50、3.3 V 参考和 1.65 V 中点 |
| 编码器 | SPI1：PA5 SCK、PA6 MISO、PA7 MOSI；PA4 CS | 三字节读帧；核对 MT6701 板的接口、电平和安装方向 |
| 调参串口 | USART2：PA2 TX、PA3 RX；115200、8N1 | USB-TTL 交叉连接并共地，使用兼容的逻辑电平 |

功率板型号、母线电压、电机额定参数和完整接线图尚未在本仓库确认齐全，因此以上只是源码引脚表，不是完整硬件复现清单。不要凭本 README 猜测供电电压。

构建顺序：打开 Keil 工程 → 确认编译器、器件包及 DSP 库路径 → Rebuild → 核对 Flash/RAM 占用 → 检查接线和限流条件后烧录。工程引用的 CMSIS-DSP 静态库随目录保存；不要因忽略编译产物而删除源工程依赖的 `.lib` 或启动文件。

启动顺序为外设初始化、电流校零、转子对齐、电角度零位记录，最后关闭 PWM 并等待命令；初始化失败进入故障状态。当前文档整理未重新构建或上板，不将历史编译日志当作最新版本的构建证明。

### 关键参数

| 参数 | 默认值 / 单位 | 注意事项 |
| --- | --- | --- |
| 电机极对数 | 7 | 必须匹配实际电机 |
| PWM / 电流环 | 目标约 20 kHz / 标称约 4 kHz | 由 TIM1 中心对齐、重复计数及触发配置推算，非本次实测 |
| 位置、速度更新 | 标称 930 Hz，定时配置约 929.37 Hz | 控制器使用标称周期，存在小幅差异 |
| 相电流保护 / Iq 限幅 | 1.55 A | 必须同时满足电机、采样链和驱动板限制 |
| 电流 PI | Kp=0.65、连续时间 Ki=80 | 按周期换算离散 Ki；输出是归一化电压，不是直接的伏特值 |
| 速度 PI | Kp=0.04538、连续时间 Ki=0.54213 | 当前串口 SET_PID 不修改速度内环 |
| 位置 P | 默认 15，上限 25，Ki 默认 0 | 历史 P=25 测试不等于源码默认值 |

### 串口协议

每次发送一条命令并以 CRLF 结束；等待应答或试验完成后再发送下一条。位置目标/反馈使用**度**，内部位置使用 rad，PID 增益按内部 rad 单位定义；反馈是连续累计位置，位置误差不是按 360° 或 720° 取最短路径。

| 命令 | 用途 | 当前限制 |
| --- | --- | --- |
| `PING` | 连通查询 | 接受后返回 `OK` |
| `STOP` | 关闭控制和 PWM | 不清除锁存故障；不保证主动刹车，转子可能惯性滑行 |
| `SET_PID,15,0,0` | 设置位置环 Kp、Ki、Kd | 仅 READY 状态；当前要求 Kd=0，增益范围见配置及控制接口 |
| `RUN_STEP,10,500` | 向逻辑位置 10° 运行 500 ms | 目标范围 [-360°,360°]，持续时间 1～5000 ms；不是相对转动 10° |
| `DATA,elapsed,target,feedback` | 运行中遥测 | 时间 ms、目标与反馈为度；期望约 10 ms 发送一次，不等于实测 100 Hz |

运行命令只是协议示例，不代表适合任意台架的安全测试值。无效、越界或状态不允许的命令可能不应答；`PING` 成功也不能证明电机已准备就绪。运行结束会关闭 PWM，而不是继续保持目标位置。
